# Threat Model

## Adversaries
- Stolen locked device
- Stolen unlocked device
- Malicious app
- Rooted/compromised host OS
- Zero-day attacker
- Malicious or compromised relay
- MITM / key substitution
- Replay / rollback attacker
- Debugging / hooking attacker
- Physical forensic attacker
- Supply-chain compromise
- Coercion scenario
- Availability/DoS attacker

## Non-goals
- Claims of absolute compromise resistance
- Claims against every hardware laboratory attack
- Claims of invisibility or untraceability
- Law-enforcement bypass

## Central research question
Can a stronger trust boundary refuse unauthorized cryptographic use even when the primary host environment is hostile?
